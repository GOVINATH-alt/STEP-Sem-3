# STEP-Sem-3: Java Programming & Data Structures Repository

Comprehensive Java implementations and solutions for all **STEP Semester 3** problem sheets, practice sessions, and assignments across all 12 weeks.

All solutions are written strictly in standard **Java only** without external libraries or command-line dependencies. Each program includes an integrated test runner in its `main` method.

## How to Checkout and Run

To switch to any week's branch:

```bash
git checkout week-1-and-2
# or
git checkout "week-1-&-2"
```

To compile and run any Java file:

```bash
javac <filename>.java
java <Classname>
```

All programs are self-contained and run without command-line arguments.
