This branch contains the solutions for Week 7 (Encapsulation and Access Modifiers) and Week 8 (Inheritance and Polymorphism) Practice and Assignment problems.

```
│   │   └── AttendanceSheet.java           # P5: Attendance Sheet Encapsulated List

```

## How to Compile and Run

No command-line arguments are required. Each file includes a self-contained `main` method that executes the sample test cases and demonstrates full functionality.

```bash
# Compile
javac <filename>.java

# Run
java <Classname>
```
