# Week 3 & 4: OOP Concepts & LeetCode Array Problems

This branch contains the solutions for Week 3 (OOP Classes & Objects) and Week 4 Practice and Assignment problems.

## Structure

```
├── week3/
│   └── oop_basics/
│       ├── SrmStudent.java              # Student OOP Model with static and instance members
│       └── Course.java                  # Course OOP Model
└── week4/
    ├── practice/
    │   ├── TwoSum.java                  # Problem 1: Two Sum
    │   ├── BestTimeToBuyStock.java      # Problem 2: Best Time to Buy and Sell Stock
    │   ├── ContainsDuplicate.java       # Problem 3: Contains Duplicate
    │   ├── MergeSortedArrays.java       # Problem 4: Merge Two Sorted Arrays
    │   └── RotateArray.java             # Problem 5: Rotate Array
    └── assignment/
        ├── ProductExceptSelf.java       # Assignment 1: Product of Array Except Self
        ├── MaximumSubarray.java         # Assignment 2: Maximum Subarray (Kadane's)
        ├── ThreeSum.java                # Assignment 3: 3Sum
        ├── SubarraySumEqualsK.java      # Assignment 4: Subarray Sum Equals K
        └── FindMinRotatedSortedArray.java # Assignment 5: Find Minimum in Rotated Sorted Array
```

## How to Compile and Run

No command-line arguments are required. Each file includes a self-contained `main` method with test cases.

```bash
# Compile any file
javac <filename>.java

# Run
java <Classname>
```
