# Week 5 & 6: Methods, 2D Arrays & OOP Encapsulation

This branch contains the solutions for Week 5 (Arrays, Methods, 2D Grids) and Week 6 (Classes, Objects, Encapsulation) Practice and Assignment problems.

## Structure

```
├── week5/
│   ├── practice/

│   │   ├── TeamDuplicateChecker.java      # P2: Team Name Duplicate Detection
│   │   ├── TopThreePodiumFinder.java      # P3: Single-pass Top 3 Podium Finder
│   │   ├── SeatingGridOptimizer.java      # P4: 2D Grid Row Average Classifier
│   │   └── CandidateShortlistEngine.java  # P5: Overloaded Eligibility & Ranking
│   └── assignment/
│       ├── FantasyScoreMultiplier.java    # A1: Captain / Vice-Captain Multipliers
│       ├── DuplicatePlayerPickChecker.java# A2: Duplicate Player Pick Detection
│       ├── TopPerformerTracker.java       # A3: Single-pass Min, Max and Spread
│       ├── MatchDayGridAnalyzer.java      # A4: 2D Cricket Match Grid Analyzer
│       └── FantasyLeagueAutoDraft.java    # A5: Overloaded Rules & Auto-Draft Ranking
└── week6/
    ├── practice/
    │   ├── PlacementRecord.java           # M1: Placement Record OOP Model
    │   ├── MessWallet.java                # M2: Encapsulated Mess Wallet
    │   ├── CourseCreditManager.java       # M3: Chained Constructor for Course
    │   ├── LibraryIdCardManager.java      # M4: Reference Equality Verification
    │   └── StudentCollegeInfoManager.java # M5: Static Members and Class Methods
    └── assignment/
        ├── LibraryInventoryManager.java   # M1: Library Inventory Record Model
        ├── PayrollSalaryManager.java      # M2: Encapsulated Salary Account
        ├── EmployeeProfileManager.java    # M3: Chained Constructor for Employee/Intern
        ├── ExamHallTicketManager.java     # M4: Hall Ticket Reference vs Object Identity
        └── EmployeeCompanyInfoManager.java# M5: Shared Company Static Information
```

## How to Compile and Run

Each file is completely self-contained with a `main` method.

```bash
# Compile
javac <filename>.java

# Run
java <Classname>
```
